# 2026 国庆 · 厦门 → 川西逆时针自驾路书

一个面向手机端实际执行的静态自驾路书 Web App。

## 核心功能

- 路段级里程 / 纯驾驶时间 / 道路编号
- 逐日折叠时间轴
- 交互地图与主要节点
- 华住住宿优先级（汉庭 3.5/3.51、新品全季等）
- 极氪 001 WE100 补能策略
- 彩云天气执行位（本地记录，避免前端暴露 API Token）
- Service Worker 基础离线缓存

## 使用

无需构建，直接使用静态文件：

```bash
python -m http.server 8080
# 然后访问 http://localhost:8080
```

也可以直接部署到 GitHub Pages / Vercel / Cloudflare Pages。

## 数据说明

里程与时间来自公开道路信息和自驾资料整理，属于**规划值**。国庆期间务必以高德实时导航、四川交警、阿坝州/甘孜州交通通告为准。

主要参考：
- 四姑娘山官方：成都—四姑娘山约 175km / 3h
- 丹巴—八美：约 84–85km / 2h+
- 新都桥—雅江：约 70km / 2h
- 雅江—理塘：约 140km / 3.5h
- 理塘—香格里拉镇：约 230km / 4h
- 新都桥—康定：约 78–80km / 1.5–2h（天气/国庆拥堵会显著增加）
- 康定—贵阳：约 827km / 10.2h
- 贵阳—厦门：近期公开攻略约 1350km，建议按 15–17h 纯驾驶窗口预估

## 安全原则

> 道路与天气安全 > 人的状态 > 电量 > 景点。
